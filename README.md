# Greenwich house pottery Measuring app code (public)

## Receipt printing:
Locations: 
  - Greenwich (Jones street)
  - Chelsea (14th Street)
  - Barrow Street (Barrow Street)

All three locations run the same `print_server_v2.exe`, built from `print_server_v2.py` by running `build_exe.bat` on Windows.
It is a single self-contained exe (no `_internal` folder). The location and its receipt printer's IP are passed on the
command line by that location's .bat file, which `build_exe.bat` writes.

Each location's folder has:
  print_server_v2.exe
  run_<location>_print_server.bat (e.g. run_chelsea_print_server.bat)
  <location>_print_server_secret_key.txt (e.g. chelsea_print_server_secret_key.txt, or as a CHELSEA_PRINT_SERVER_SECRET_KEY ENV variable; not provided here)

Run the location's .bat file, which opens a command prompt and runs e.g. `print_server_v2.exe Chelsea --printer-ip 10.186.3.27`.
The secret key file must be in the folder the .bat file is run from.
If the printer's IP changes, edit the `--printer-ip` value in the .bat file; no rebuild is needed.

Only one print server per location can run on a computer: a second copy prints
"Another <location> print server is probably already running on this computer" and exits. Close the other window first.
(Each location's print server holds a localhost port while it runs: Barrow 48631, Chelsea 48632, Greenwich 48633.)
If no other copy is running, the line above that message gives the actual error; Windows can reserve port ranges
for Hyper-V or WSL, which `netsh interface ipv4 show excludedportrange protocol=tcp` lists.

The server marks receipts printed when it hands them to the print server, so receipts that fail to print
(e.g. the printer is off) are kept in `<location>_unprinted_receipts.json` (e.g. `chelsea_unprinted_receipts.json`)
in the same folder and retried every poll, including after the window is closed and reopened. Don't delete that file
unless its receipts have been printed some other way. If it is ever unreadable, it is renamed to
`<location>_unprinted_receipts.json.unreadable-<timestamp>` and kept for a person to look at.

Everything the print server shows in its window is also written, with the time on each line, to a log file per day in
`<location>_print_server_logs\` (e.g. `barrow_print_server_logs\barrow_print_server_2026-10-30.log`) in the same folder.
Files older than 60 days are deleted. When printing stops, that day's log shows which of these happened:
- `Connection failed`, `Request timed out` or `Server error` lines: the computer couldn't reach the site.
- `Failed to print job` lines: the site handed over receipts but the printer couldn't be reached.
- A `This check is N minutes late` line: the program wasn't running in between, e.g. the computer was asleep.
- A gap in the times that ends with `Starting optimized print server`: the program was closed or crashed, and was started again.

The print server also turns off the window's QuickEdit Mode when it starts. With QuickEdit on, a click inside the
window selects text and pauses the program until a key is pressed, which looks like printing silently stopping.

The print server sends its key in an `X-Print-Server-Key` header. The server still accepts the older `?secret_key=`
query parameter for exes built before that change; once every location runs a rebuilt exe, that fallback can be removed
from `get_print_jobs_optimized` in `measure/views.py`.

To test the print server code (printer and HTTP are mocked):
`uv run --with python-escpos --with requests python -m unittest test_print_server_v2`

Chelsea's key is the server's `PRINT_SERVER_SECRET_KEY`; the old Chelsea exe read it from `print_server_secret_key.txt`.
Greenwich's and Barrow's key file names are unchanged from their old exes.

Each receipt prints at the location chosen on the measure-a-piece page. That menu starts at the location last
chosen on the same browser (remembered in a `last_piece_location` cookie when a piece is submitted), or at the member's
saved location on a browser that hasn't submitted a piece yet.

The receipt text is generated by the server. Chelsea and Greenwich print the same slip wording as before the move to v2;
Barrow keeps its own wording.
